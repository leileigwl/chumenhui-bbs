# 楚门会 AI 论坛前端展示版

这是一个基于 React + Vite 的纯前端展示项目，用来还原原始论坛原型，并补齐前端可交互能力，方便直接部署到静态服务器展示。

## 项目特点

- 保留原始论坛原型的整体布局与视觉结构
- 基于 React + Vite 运行，便于本地开发和静态部署
- 支持帖子图片展示与本地上传预览
- 支持 `16:9` 与 `9:16` 图片内容接入
- 支持前端筛选、帖子详情、分享弹层、收藏交互等展示能力
- 不依赖后端接口，适合作为展示站或原型站

## 本地运行

```bash
npm install
npm run dev
```

默认开发地址：

```bash
http://127.0.0.1:5173
```

## 打包预览

```bash
npm run build
npm run preview
```

默认预览地址：

```bash
http://127.0.0.1:4173
```

## 项目结构

```text
src/
  legacy/        原始原型逻辑迁移层
  main.jsx       Vite 入口
  styles.css     外层展示样式
public/
  uploads/       静态图片资源
```

## 说明

- 当前为纯前端展示版，不接真实接口
- 数据主要来自 `src/legacy/data.js`
- 原型逻辑通过 `src/legacy/runtime.jsx` 按依赖顺序挂载运行

## 部署

这是标准 Vite 静态项目，构建产物位于 `dist/`，可直接部署到任意静态服务器。
